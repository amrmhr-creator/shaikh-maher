# موقع تراث الشيخ ماهر إسماعيل جاهين

أرشيف دروس الشيخ ماهر إسماعيل جاهين رحمه الله وكتبه وفوائده. مبني بـ [Astro](https://astro.build) ويعمل كتطبيق Node.js على الاستضافة، والمحتوى محفوظ في قاعدة بيانات MySQL.

## لوحة التحكم

من `/admin` (مثل `shaikhmaher.com/admin`) تدخل باسم مستخدم وكلمة مرور، وتضيف أو تعدل:

- **الدروس الصوتية**: العنوان والرقم والملف الصوتي والموضوعات والتفريغ النصي.
- **الفوائد**: نص الفائدة ومصدرها (درس + توقيت، أو كتاب + فصل) ومقطع مرفق، ولا تظهر إلا إذا كانت «منشورة».
- **الكتب والرسائل**: الوصف والغلاف وملف PDF والفصول.
- **مكتبة الصور**: رفع عدة صور مرة واحدة، ثم تعديل تعليق كل صورة وترتيبها.

أي حفظ يظهر على الموقع مباشرة. ومن صفحة «الحساب» تغير كلمة المرور وتضيف مستخدمين آخرين.

أول تشغيل ينشئ الجداول بنفسه، وينقل المحتوى الموجود في `src/content/` إلى القاعدة مرة واحدة، وينشئ أول مستخدم من `ADMIN_USERNAME` و`ADMIN_PASSWORD`.

## ترتيب الكود

- `src/lib/schemas.ts`: شكل بيانات كل نوع محتوى (الدروس، الفوائد، الكتب، الصور).
- `src/lib/admin.ts`: حقول نموذج لوحة التحكم لكل نوع. إضافة حقل جديد = سطر في `schemas.ts` وسطر هنا، ثم استخدامه في صفحة العرض.
- `src/lib/content.ts` و `src/lib/db.ts`: القراءة والحفظ في MySQL (كل الاستعلامات بمعاملات `?`).
- `src/lib/auth.ts` و `src/middleware.ts`: الدخول والجلسات وحماية `/admin` والتحويلات من الموقع القديم.
- `src/pages/`: صفحات الموقع، و `src/pages/admin/`: صفحات اللوحة.
- `src/content/`: المحتوى الأولي فقط؛ بعد أول تشغيل التعديل يكون من اللوحة.
- `tools/`: أدوات تجهيز الصوت والفوائد والكتب، و `docs/`: خطة الموقع وطلبات التعديل، و `brand/`: صور اللوجو.

## التشغيل والنشر

الإعدادات كلها متغيرات بيئة، وهي موضحة في [`.env.example`](.env.example): بيانات قاعدة البيانات، و`SESSION_SECRET`، وأول مستخدم، ومكان حفظ الملفات المرفوعة.

```sh
npm install
npm run build
npm start        # node ./dist/server/entry.mjs ، ويقرأ HOST و PORT
```

على Hostinger: تطبيق Node.js، أمر البناء `npm run build`، وأمر التشغيل `npm start`. يفضل ضبط `UPLOAD_DIR` على مجلد نطاق الوسائط (`media.shaikhmaher.com`) و`UPLOAD_URL` على رابطه، حتى لا تُمسح الصور والملفات مع كل نشر.

## الفحص

كل دفع يشغّل `.github/workflows/check.yml`: يبني الموقع ويشغله مع MySQL، ثم يجرب الصفحات ولوحة التحكم عبر `scripts/smoke-test.sh`.
