# تحسين صوت الدروس

## اللي لقيناه في التسجيلات (3، 4، 5، 6)
- فيه وِش خلفية ثابت (غالباً من شريط الكاسيت).
- الصوت مكتوم: أغلب الطاقة بين 200 و1000 هرتز، ومفيش أي ترددات فوق ~4 كيلوهرتز (غالباً من مصدر قديم زي كاسيت).
- فيه نغمات تشويش ثابتة بين 9 و16 كيلوهرتز.
- مستوى الصوت مختلف بين الملفات (من -18.7 لـ -16.4 LUFS).

## المعالجة (`enhance.py`)
1. قص الترددات تحت 90 هرتز وفوق 4.8 كيلوهرتز (بيشيل نغمات التشويش، ومفيش كلام هناك أصلاً).
2. شيل الوِش: بصمة الضوضاء بتتاخد من أهدى لحظات نفس الدرس وتتشال بالطرح الطيفي (noisereduce). `--denoise 0.8` (متوسطة، الافتراضي) بتقلل الوِش ~9 ديسيبل، و`0.95` (قوية) ~16 ديسيبل، وصوت الشيخ بيتأثر أقل من 2 ديسيبل.
3. EQ: تقليل الكتمة حوالين 500 هرتز، ورفع 1.4 و2.6 و3.6 كيلوهرتز لوضوح الحروف، وبعدها ضغط خفيف. (اتشال الـ de-esser لأنه كان بيبوّظ الصوت في درس 6.)
4. توحيد مستوى الصوت (loudnorm بمرورين على -16 LUFS)، وبعدين رفع ثابت 5 ديسيبل + limiter، فالنتيجة النهائية حوالي -14 LUFS (زي يوتيوب وسبوتيفاي).
5. تصدير MP3 mono بجودة 96kbps (حوالي 43 ميجا للساعة).

RNNoise اتجرب واتلغى لأنه كان بيضعف صوت الشيخ نفسه (~10 ديسيبل).

## الاستخدام
```
python3 enhance.py 3.mp3 3-enhanced.mp3                 # الإعداد الافتراضي
python3 enhance.py 3.mp3 3-enhanced.mp3 --strength 0.7  # تعديل أخف
python3 enhance.py 3.mp3 3-enhanced.mp3 --strength 1.3  # تعديل أقوى
```
بيحتاج ffmpeg و`pip install numpy noisereduce`. الدرس الواحد بياخد حوالي 5 دقايق.

## الملفات
- `samples/`: مقاطع 3 دقايق قبل وبعد (درس 1 بدرجتين تنقية).
- `enhanced/`: الدروس من 1 لـ 10 كاملة بالتنقية المتوسطة.
