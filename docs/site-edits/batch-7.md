# باتش ٧ (٢٤ أكتوبر ٢٠٢٦)

1. لوحة التحكم: مكان لرفع لوجو جديد للموقع (صفحة «إعدادات الموقع»)، ويظهر أعلى كل الصفحات.
2. الرئيسية: ترتيب بوكسات الأقسام يبقى: تعريف بالشيخ، التسجيلات، الكتب، الفوائد، الشيخ فتح الله، مكتبة الصور.
3. مكتبة الصور: أسماء الصور تبقى أرقام بالترتيب من أول صورة لآخر صورة (بدل FB IMG …)، لحين كتابة تعليقات حقيقية.
