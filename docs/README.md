# ملاحظات المشروع

- [`website-plan/`](website-plan/): خطة الموقع، وأسلوب كتابة الأوصاف، ونصوص للمراجعة.
- [`site-edits/`](site-edits/): طلبات التعديل على الموقع مجمّعة في دفعات (batch-1 … ) بالترتيب، وكل دفعة نُفذت بعد الموافقة عليها.

صور اللوجو الأصلية في [`../brand/`](../brand/). اللوجو الظاهر على الموقع يُرفع من لوحة التحكم (إعدادات الموقع).
